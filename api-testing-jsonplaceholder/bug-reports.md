# Баг-репорты — JSONPlaceholder API

BUG-01: DELETE /posts/{id} не удаляет ресурс физически

Шаги воспроизведения - 1. DELETE /posts/1 → получен 200 OK. 2. GET /posts/1 пост всё ещё возвращается с полным телом.
Ожидаемый результат - После успешного удаления повторный GET должен вернуть 404 
Фактический результат - Повторный GET возвращает 200 OK и исходные данные поста 
Приоритет / severity - Low (ожидаемое поведение для mock-API без реальной БД, но задокументировано как отклонение от REST-конвенций) 


BUG-02: POST /posts без обязательного поля title не возвращает ошибку валидации

Шаги воспроизведения - 1. POST /posts с телом, где отсутствует поле title (есть только body и userId). 2. Проверить код ответа. 
Ожидаемый результат - 400 Bad Request с указанием, что поле title обязательно 
Фактический результат - API возвращает 201 Created, ресурс "создаётся" без обязательного поля 
Приоритет / severity - Medium — отсутствие валидации обязательных полей на входе
