# API Testing — JSONPlaceholder

Тестирование публичного mock REST API [jsonplaceholder.typicode.com](https://jsonplaceholder.typicode.com) — покрыты эндпоинты `/posts`, `/users`, `/comments`.

## Как воспроизвести

1. Установи [Postman](https://www.postman.com/downloads/).
2. Импортируй `postman_collection.json` (кнопка **Import** в Postman).
3. Открывай запросы по очереди и нажимай **Send**.
4. Смотри вкладку **Test Results** под ответом — там автоматически проверяется код ответа и структура данных для каждого запроса.
5. Сверяй фактический результат с колонкой «Ожидаемый результат» в `test-cases.md`.

## Файлы

| Файл | Описание |
|---|---|
| `postman_collection.json` | 15 запросов с автотестами (готово к импорту в Postman) |
| `test-cases.md` | Тест-кейсы в табличном виде: сценарий, ожидаемый результат, приоритет |
| `bug-reports.md` | Оформленные баг-репорты по найденным расхождениям |

## Область тестирования

- CRUD-операции: GET, POST, PUT, PATCH, DELETE
- Позитивные и негативные сценарии (несуществующий id, невалидные данные, пустое тело запроса)
- Проверка заголовков ответа и времени отклика
- Вложенные ресурсы и фильтрация (`/users/1/posts`, `/comments?postId=1`)
