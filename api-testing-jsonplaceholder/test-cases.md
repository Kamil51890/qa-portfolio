# Тест-кейсы — JSONPlaceholder API

Заполни столбец **Фактический результат** после прогона запросов в Postman.

| ID | Сценарий / шаги | Ожидаемый результат | Приоритет | Фактический результат |
|---|---|---|---|---|
| TC-01 | GET /posts — получить список постов | 200 OK; тело — массив из 100 объектов post | High | |
| TC-02 | GET /posts/1 — получить пост по существующему id | 200 OK; тело — объект с полями userId, id, title, body | High | |
| TC-03 | GET /posts/9999 — запрос с несуществующим id | 404 Not Found (или пустой объект — зафиксировать фактическое поведение) | High | |
| TC-04 | GET /posts/abc — запрос с нечисловым id | Ожидается 400/404; проверить, что реально возвращает API | Medium | |
| TC-05 | POST /posts — создать пост с валидным телом (title, body, userId) | 201 Created; в ответе присутствует новый id | High | |
| TC-06 | POST /posts — тело запроса без обязательного поля title | Ожидается 400; проверить фактический код ответа | Medium | |
| TC-07 | POST /posts — тело запроса пустое {} | API не падает с 500; зафиксировать реальный ответ | Medium | |
| TC-08 | PUT /posts/1 — обновить существующий пост полностью | 200 OK; тело ответа отражает обновлённые поля | High | |
| TC-09 | PATCH /posts/1 — частично обновить одно поле (title) | 200 OK; изменено только указанное поле | Medium | |
| TC-10 | DELETE /posts/1 — удалить существующий пост | 200 OK; повторный GET /posts/1 — проверить, реально ли пост удалён | Medium | |
| TC-11 | GET /users — список пользователей | 200 OK; каждый объект содержит id, name, email, address | High | |
| TC-12 | GET /users/1/posts — посты конкретного пользователя (вложенный ресурс) | 200 OK; все посты в ответе имеют userId = 1 | Medium | |
| TC-13 | GET /comments?postId=1 — фильтрация комментариев по параметру | 200 OK; все элементы имеют postId = 1 | Medium | |
| TC-14 | Проверка заголовков ответа (Content-Type) | Content-Type: application/json; charset=utf-8 | Low | |
| TC-15 | Проверка времени ответа GET /posts | Ответ приходит в разумных пределах (< 1–2 сек); зафиксировать фактическое время | Low | |
