# QA Portfolio — Камиль Нигматзянов

Портфолио самостоятельных проектов по тестированию, подготовленное при отклике на вакансию тестировщика мобильных приложений.

## Проекты

### 1. [API Testing — JSONPlaceholder](./api-testing-jsonplaceholder)
Тестирование публичного REST API: 15 тест-кейсов (позитивные, негативные, граничные сценарии), Postman-коллекция с автоматическими проверками, оформленные баг-репорты.

**Стек:** Postman, REST, JSON

### 2. [Mobile Login Test Plan](./mobile-login-test-plan)
Тест-план и 15 тест-кейсов для экрана авторизации мобильного приложения: функциональность, UI, граничные значения, платформенные различия Android/iOS, accessibility.

**Стек:** тест-дизайн, тест-документация
