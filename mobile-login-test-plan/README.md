# Mobile Login Test Plan

Тест-план и тест-кейсы для экрана авторизации мобильного приложения (email + пароль).

Это проект по тест-дизайну без выполнения (нет реального приложения под рукой) — показывает владение техниками: эквивалентные классы, граничные значения, негативное тестирование, платформенные различия Android/iOS.

Если появится доступ к реальному приложению (своё или тестовое демо) — эти же тест-кейсы можно прогнать вручную и дописать фактические результаты, как в проекте с API.
